⚡ 1B. Cài Đặt Cơ Sở Dữ Liệu Riêng Supabase (Tốc độ 0.05s & Realtime)

Khuyên dùng
Chưa cấu hình

Lưu trữ dữ liệu học viên trong Database PostgreSQL riêng của bạn trên đám mây. Tốc độ mở bảng chỉ 0.05 giây, bảo vệ dữ liệu vĩnh viễn và tự động cập nhật đơn mới tức thì!

📌 HƯỚNG DẪN 3 BƯỚC THIẾT LẬP SUPABASE (HOÀN TOÀN MIỄN PHÍ):
  1. Truy cập supabase.com ➔ Bấm "Start your project" (Đăng nhập bằng GitHub hoặc Email) ➔ Bấm "New project".
  2. Tại menu bên trái của Supabase, bấm vào biểu tượng SQL Editor ➔ Bấm "New query" ➔ Dán toàn bộ đoạn mã bên dưới vào rồi bấm nút RUN:
🔒 Lưu ý bảo mật dữ liệu Supabase: Chính sách bên dưới cho phép Website tự động lưu đơn học viên. Đối với hệ thống đã có Google Sheets làm lớp khoá bảo vệ chính với ADMIN_SECRET_KEY, dữ liệu trên Google Sheets đã được bảo mật 100% không cho người lạ đọc. 
-- 1. Tạo bảng lưu học viên đăng ký khóa học
CREATE TABLE IF NOT EXISTS public.leads (
    id BIGSERIAL PRIMARY KEY,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    time_str TEXT,
    name TEXT NOT NULL,
    phone TEXT NOT NULL,
    email TEXT,
    price TEXT,
    course TEXT,
    occupation TEXT,
    channel TEXT,
    status TEXT DEFAULT 'Chờ thanh toán',
    email_status TEXT
);

-- 2. Bật bảo mật dữ liệu Row Level Security
ALTER TABLE public.leads ENABLE ROW LEVEL SECURITY;

-- 3. Cấp quyền cho Website lưu đơn & Admin quản lý
CREATE POLICY "Public Insert Leads" ON public.leads FOR INSERT WITH CHECK (true);
CREATE POLICY "Public Select Leads" ON public.leads FOR SELECT USING (true);
CREATE POLICY "Public Update Leads" ON public.leads FOR UPDATE USING (true);
CREATE POLICY "Public Delete Leads" ON public.leads FOR DELETE USING (true);

-- 4. Bật Realtime cập nhật tức thì
ALTER PUBLICATION supabase_realtime ADD TABLE public.leads;

3. Vào Project Settings (biểu tượng bánh răng góc dưới trái) ➔ chọn mục API ➔ Copy Project URL và anon public key dán vào 2 ô phía trên rồi bấm "Lưu"!

Tự Động 10 Phút
