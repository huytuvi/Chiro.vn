# Chiro.vn - Dự án Website Khóa Học Nắn Chỉnh Cột Sống Chuyên Biệt (Specific Chiropractic)

## 📌 Giới thiệu
Trang Landing Page giới thiệu và đăng ký Khóa học Gieo Mầm Nắn Chỉnh Cột Sống Chuyên Biệt của Chuyên gia Bác sĩ Henrik Simon (Simon Center).

## 📂 Danh sách tệp
- `index.html`: Trang Landing Page chính thức (bao gồm đếm ngược tăng giá, tính năng đăng ký, thanh toán quét mã VietQR tự động).
- `admin-confirm.html`: Trang quản trị dành riêng cho admin để xác nhận tiền chuyển khoản, gửi email kích hoạt tự động qua EmailJS và xuất file Excel đăng ký.
- `logo.png`: Logo Simon Center.

## 🛠 Cách sử dụng trên Claude hoặc các AI khác
Bạn có thể mở trực tiếp thư mục này trên Claude Code, Cursor, VS Code để tiếp tục chỉnh sửa và lập trình song song.
